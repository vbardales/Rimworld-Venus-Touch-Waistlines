# Private local texture pack

This directory is a local, non-publishable compatibility package.  Its 81
textures are derived from LEWD Hooman Apparel (GilieArt, Workshop 3275648920)
and fitted to WDI's Realistic Bodies (Workshop 3527486510).  Neither source
ships a redistribution licence.  Keep this folder out of Git, Steam uploads,
and the Venus `Mod/` package unless the respective authors grant permission.

It contains no DLL, C#, Harmony patch, gameplay logic, recipe, or Hooman Cute
dependency.  The three XML definitions exist only because RimWorld cannot load
standalone apparel textures.
